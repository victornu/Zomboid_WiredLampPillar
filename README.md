# Wired Lamp Pillar

Mod pour **Project Zomboid** permettant de connecter les lampes sur poteaux en bois à un générateur.

## Dépendances

- StarlitLibrary

## Installation

1. Téléchargez le mod
2. Placez-le dans le dossier `mods` de Project Zomboid
3. Activez-le dans le menu des mods du jeu
